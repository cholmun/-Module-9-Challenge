# -Module-9-Challenge
Repository for Module 9 challenge; External API demo
## Description
!!WORK IN PROGRESS!!

This project demonstrates the use of external APIs to fetch and display data. It includes examples of making API requests, handling responses, and updating the UI with the retrieved data.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/cholmun/Module_9_Challenge.git
    ```
2. Navigate to the project directory:
    ```bash
    cd Module_9_Challenge
    ```
3. Install the dependencies:
    ```bash
    npm install
    ```

## Usage
1. Start the application:
    ```bash
    npm start
    ```
2. Open your browser and navigate to `http://localhost:3000`.

## Features
- Fetch data from an external API
- Display data in a user-friendly format
- Handle loading and error states

## Technologies Used
- JavaScript
- Node.js
- Express
- HTML/CSS
